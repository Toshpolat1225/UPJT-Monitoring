Iltimos, loyiha katalogiga kiring va quyidagi vazifalarni bajarib, natijalarni ko'rsating:

1. git branch --show-current
2. git status --short
3. git rev-parse --short origin/stable-version
4. git rev-parse --short HEAD
5. git diff --name-status origin/stable-version -- src/pages src/components src/App.tsx src/context src/lib

- branchlar commit bo'yicha bir xilmi yoki farq bormi?
- working tree ichida qaysi frontend fayllar farq qilayotganini ayting.
- backend/API/Postgres bilan bog'liq fayllar farq qiladimi yoki yo'qmi?
